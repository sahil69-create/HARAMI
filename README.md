# Harami Gamer | YouTube Portfolio

This is a professional YouTube portfolio website for **Harami Gamer**, a Free Fire competitive player and keymapping expert. The website showcases his gameplay highlights, performance metrics, and professional gaming services.

## Features

- **Hero Section**: A dynamic hero section with a typing animation, background music, and a professional layout.
- **Animated Stats**: Real-time performance metrics (Subscribers, Views, Live Streams, Rank) with animated counters.
- **Video Highlights**: A grid of the latest YouTube highlights with professional thumbnails and hover effects.
- **Live Stream Panel**: A dedicated section to promote live streams with a "Live Now" badge.
- **Pro Gaming Services**: A section outlining professional services like sponsored streams and game promotions.
- **Contact Form**: A functional contact form for sponsorships and squad collaborations.
- **Responsive Design**: Fully responsive layout optimized for mobile, tablet, and desktop screens.
- **Custom Loader**: A sleek loading screen for a professional user experience.

## Project Structure

- `index.html`: Main HTML document with the structure of the portfolio.
- `styles.css`: Custom CSS for modern styling, responsive design, and animations.
- `script.js`: JavaScript for animations, stats counters, typing effect, and background music.
- `assets/`: Directory for audio files (e.g., background music).
- `images/`: Directory for image assets (e.g., video thumbnails).

## How to Run

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. Enjoy the professional Harami Gamer portfolio experience!

## Technologies Used

- HTML5
- CSS3 (Custom Variables, Flexbox, Grid, Animations)
- JavaScript (Vanilla JS for animations and interactivity)
- Google Fonts (Orbitron & Rajdhani)
